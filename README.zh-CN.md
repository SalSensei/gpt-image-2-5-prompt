# GPT Image 2.5 提示词创作助手

[English](README.md) | **简体中文**

把一个图像想法，写成清晰、细致、可直接使用的 GPT Image 2.5 提示词。

这个 Codex 技能会帮助你明确画面要表达什么，讨论重要的视觉选择，再写出完整的图像生成提示词。交流使用中文，最终提示词使用英文。

**它只撰写提示词，不生成图片，也不会消耗生图额度。**

## 它能帮你做什么

- 将简短的想法发展成明确的图像方案。
- 优化已有提示词，同时保留重要要求。
- 明确每张参考图的用途，例如人物身份、服装、构图或风格。
- 撰写局部修改和后续迭代的提示词。
- 比较不同视觉方向，再选择合适的方案。
- 检查提示词中是否存在矛盾、多余内容，或难以在画面中呈现的细节。

题材覆盖人物与时尚、产品与食物、建筑空间、自然、叙事场景、平面设计、图解与界面预览、抽象艺术、表面图案和系列作品。表现形式支持摄影、绘画、插画、三维、版画、拼贴及混合媒介。

它不会默认所有图片都应该写实、奢华或细节繁多。如果简洁更适合你的想法，作品就应该保持简洁。

## 如何与你协作

需求明确时，技能可以直接撰写提示词。面对复杂或尚未确定方向的需求，它会先讨论那些真正影响结果的选择，再开始成稿。

它会从两个角度检查草稿：是否忠实保留你的要求，以及各项视觉选择是否协调。最后再校验正文长度。

你会得到：

- 一份完整、可复制的英文提示词。
- 一条中文字符数说明；能够运行本地校验时，会提供准确统计。
- 必要时提供简短说明或生成参数建议。
- 提示词超过 8,000 字符时，附上内容一致的文本文件；你也可以主动要求文件。

每份提示词最多 **31,500 字符，包含空格和换行**。这是本技能设定的上限，不代表 GPT Image 2.5 的 API 限制。没有最低长度要求，也不会为了写得更长而重复内容。

## 安装

1. 在仓库页面选择 **Code → Download ZIP**，下载后解压。
2. 如果解压后的文件夹名称带有 `-main` 等分支后缀，将其改为 `gpt-image-2-5-prompt`。
3. 将整个文件夹放入 Codex 技能目录：`~/.codex/skills/`。如果你配置了自定义位置，则使用 `$CODEX_HOME/skills/`。
4. 保留文件夹中的全部内容。只复制 `SKILL.md` 会遗漏它需要的参考资料和校验工具。

安装后的目录结构应如下所示：

```text
~/.codex/skills/gpt-image-2-5-prompt/
├── SKILL.md
├── agents/
├── references/
├── scripts/
└── tests/
```

如果已经安装过旧版本，请先备份再替换。准确统计字符数需要 Python 3，校验工具不需要安装额外的 Python 软件包。

## 开始使用

调用 `$gpt-image-2-5-prompt`，再描述你的需求。你可以附上参考图，也可以粘贴已有提示词。

例如：

```text
使用 $gpt-image-2-5-prompt，帮我设计一张克制的拉丝不锈钢水壶产品照片。
完整展示水壶，不出现品牌标识。
```

```text
使用 $gpt-image-2-5-prompt，先比较抽象展览海报的三种视觉方向，
再撰写最终提示词。
```

```text
使用 $gpt-image-2-5-prompt，优化下面这份提示词。
保留人物、姿态和服装，删除相互矛盾的描述。
```

你可以全程用中文提出需求。提示词指令会以英文输出；如果画面需要出现指定的中文或其他语言文字，这些文字会保留原文。

## 需要提供哪些信息

从你已经想清楚的部分开始即可。主体、用途、表现形式、构图、指定文字，以及必须保持不变的内容，都有帮助。

使用参考图时，可以说明每张图希望借鉴什么。修改图片时，请提供原图和需要改变的内容。不必先填写一份冗长的问卷才能开始。

## 需要了解的边界

更好的提示词能让要求更清楚，但不能保证每次都生成完美图片。成图中的文字、人物身份、物体形状，以及修改区域之外的细节，仍需检查。如果某一区域必须逐像素不变，需要另行采用图像合成流程。

每个新创作任务开始时，技能会尝试核对 [GPT Image 2.5 官方指南](https://developers.openai.com/api/docs/guides/image-prompting#gpt-image-2.5-guide)。如果无法访问，它会说明情况，并使用记录了核验日期的参考资料。如果无法运行字符校验，也会说明统计尚未核验，不会编造数字。

初次验证覆盖技能结构、13 项字符校验自动测试，以及由作者完成的示例走查；未进行实际生图质量测试。

这是一个独立制作的技能，并非 OpenAI 官方产品。
